YERBA MATE CHALLENGE - VERSION ONLINE
======================================
Esta versión permite crear una sala con un código y que varios celulares se conecten al mismo juego en tiempo real.

Para probarla en una computadora:
1. Instalar Node.js.
2. Abrir una terminal dentro de esta carpeta.
3. Ejecutar: npm install
4. Ejecutar: npm start
5. Abrir http://localhost:3000

Para que tus compañeros entren desde sus celulares desde Internet, el proyecto debe publicarse en un servicio que ejecute Node.js (por ejemplo un hosting compatible con WebSockets). Una vez publicado, todos usan la misma dirección web y el código de sala.

El juego tiene 50 segundos por pregunta, preguntas más complejas, verdadero/falso, mito/evidencia, adivinanzas visuales con órganos y ranking compartido por sala.
